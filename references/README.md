# References / 参考文档

本目录存放 Quantitative UX Research 技能的方法论参考文档。

This directory contains methodology reference documents for the Quantitative UX Research skill.

## 目录结构 / Directory Structure

| 文件 / File | 内容 / Content |
|------|------|
| `heart-framework.md` | HEART 框架完整指南（Goals-Signals-Metrics 映射表） |
| `csat-methods.md` | CSat 调查设计与分析方法论 |

| `maxdiff-guide.md` | MaxDiff 优先级排序方法指南 |

## 使用方法 / Usage

这些参考文档供 AI Agent 在执行量化研究任务时查阅，不需要手动维护。

These reference documents are consulted by the AI Agent during quantitative research tasks and do not require manual maintenance.

## 🌐 技能生态关联 / Skill Ecosystem Connections

QuantUX 负责用数据验证其他技能的定性假设：

- **UDM → QuantUX**: UDM 的定性发现（访谈洞察） → QuantUX 设计 A/B 测试进行验证
- **JTBD → QuantUX**: JTBD 的机会评分 → QuantUX 量化验证，计算统计显著性
- **VPD → QuantUX**: VPD 的价值假设 → QuantUX 实验设计与样本量计算
- **Persona → QuantUX**: Persona 的角色假设 → QuantUX 行为数据验证
- **QuantUX → SWD**: QuantUX 的分析结果 → SWD 进行数据叙事和可视化改造

基于《Quantitative User Experience Research》(Chapman & Rodden, 2023) 的方法论体系。

Based on the methodology framework from *Quantitative User Experience Research* (Chapman & Rodden, 2023).

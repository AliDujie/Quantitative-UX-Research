# References

## 目录结构

| 文件 | 内容 |
|------|------|
| `heart-framework.md` | HEART 框架完整指南（Goals-Signals-Metrics 映射表） |
| `csat-methods.md` | CSat 调查设计与分析方法论 |

这些参考文档供 AI Agent 在执行研究任务时查阅，不需要手动维护。

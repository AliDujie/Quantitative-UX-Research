# CSat 调查设计与分析方法论

> 基于 Chapman & Rodden《Quantitative User Experience Research》(2023)

---

## CSat（Customer Satisfaction）概述

CSat 是最直接的用户满意度测量方法，通过简短问卷收集用户对特定体验的满意度评分。

### 核心特点

- **简单直接** — 通常 1-5 个问题，用户负担低
- **高频可用** — 可在每次交互后发送，适合追踪趋势
- **场景特定** — 针对具体功能/流程/交互，而非整体满意度
- **快速行动** — 结果立即可用，适合快速迭代

---

## CSat 问卷设计

### 标准评分格式

**5 分制李克特量表（推荐）：**

```
您对此次体验的满意度如何？
□ 非常不满意  □ 不满意  □ 一般  □ 满意  □ 非常满意
   1            2         3       4        5
```

**7 分制（更精细区分）：**

```
□ 非常不满意 □ 不满意 □ 有些不满意 □ 中立 □ 有些满意 □ 满意 □ 非常满意
   1            2          3          4       5          6       7
```

### 问卷结构

**Part 1: 核心满意度评分**
- 1 个主要满意度问题（必选）

**Part 2: 维度评分（可选）**
- 功能满意度
- 易用性满意度
- 价值满意度

**Part 3: 开放反馈**
- "您最满意的是什么？"
- "您最不满意的是什么？"
- "有什么改进建议？"

**Part 4: 用户标识**
- 用户 ID / 会话 ID（用于关联行为数据）

## CSat 发送策略

### 触发时机

| 触发类型 | 时机 | 适用场景 |
|----------|------|----------|
| 交易后 | 完成购买/预订后 | 电商、预订平台 |
| 功能使用后 | 使用特定功能后 | SaaS、工具类产品 |
| 客服后 | 客服交互结束后 | 客服满意度 |
| 周期性 | 月度/季度定期 | 整体满意度追踪 |

### 发送渠道

| 渠道 | 响应率 | 优点 | 缺点 |
|------|--------|------|------|
| In-App | 15-25% | 即时、上下文相关 | 可能打断用户 |
| Email | 5-15% | 不 intrusive、可详细 | 响应率低 |
| Push | 3-8% | 高触达 | 可能引起反感 |
| SMS | 10-20% | 高打开率 | 字数限制 |

## CSat 数据分析

### 基本统计

| 指标 | 计算公式 | 解读 |
|------|----------|------|
| 平均 CSat | Σ(评分) / 响应数 | 整体满意度水平 |
| 满意率 | (4+5 分响应数) / 总响应数 | 满意用户占比 |
| 不满意率 | (1+2 分响应数) / 总响应数 | 不满意用户占比 |
| 净满意度 | 满意率 - 不满意率 | 类似 NPS 的净指标 |

### 趋势分析

1. **时间序列** — 追踪 CSat 月度/周度趋势
2. **Cohort 分析** — 不同用户群体的 CSat 差异
3. **功能对比** — 不同功能/流程的 CSat 对比
4. **用户细分** — 新老用户、付费免费用户的 CSat 差异

### 开放反馈分析

1. **主题编码** — 将开放反馈归类为 5-10 个主题
2. **情感分析** — 正面/负面/中性情感比例
3. **关键词提取** — 高频关键词和短语
4. **用户原话引用** — 选择代表性的用户原话

## CSat vs NPS vs SUS

| 维度 | CSat | NPS | SUS |
|------|------|-----|-----|
| **测量对象** | 特定体验满意度 | 推荐意愿 | 系统可用性 |
| **问题数** | 1-5 | 1 | 10 |
| **评分** | 1-5 或 1-7 | 0-10 | 1-5 (李克特) |
| **响应时间** | < 1 分钟 | < 30 秒 | 2-3 分钟 |
| **适用频率** | 高频（每次交互后） | 中频（月度/季度） | 低频（季度/版本） |
| **行动导向** | 高（具体体验） | 中（整体忠诚） | 高（可用性改进） |
| **最佳用途** | 流程/功能满意度 | 用户忠诚度 | 产品可用性 |

## 实战案例：旅行预订平台 CSat

### 调查设计

```
标题: 您的预订体验如何？

Q1. 您对此次预订体验的满意度如何？ (1-5)
Q2. 预订流程的易用性如何？ (1-5)
Q3. 您找到的酒店选择是否满足需求？ (1-5)
Q4. 您最满意的是什么？ (开放)
Q5. 有什么可以改进的？ (开放)
```

### 发送策略

- **触发**: 用户完成预订确认后
- **渠道**: In-App 弹窗
- **时机**: 确认页面展示后 3 秒
- **频率**: 每次预订一次，不重复

### 分析框架

```
CSat 分数分布 → 趋势分析 → 用户细分 → 开放反馈主题编码 → 行动项
```

## 常见陷阱

1. **问卷过长** — CSat 应保持简短（1-5 题），超过 5 题响应率下降 50%+
2. **发送时机不当** — 在用户完成关键任务前发送，导致评分偏差
3. **忽略低响应率** — 响应率低时样本可能有偏差（只有极端满意/不满意的用户会回复）
4. **不关联行为数据** — CSat 分数应与用户行为数据关联分析
5. **只收集不行动** — 每个 CSat 结果都应有对应的改进行动

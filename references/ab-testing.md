# A/B 测试设计原则与最佳实践

> 基于 Chapman & Rodden《Quantitative User Experience Research》(2023) 及 Kohavi《Trustworthy Online Controlled Experiments》

---

## A/B 测试概述

A/B 测试（随机对照实验）是量化 UX 研究的核心方法，通过随机分配用户到不同版本，因果推断设计变更的效果。

### 核心原理

```
随机分配 → 控制变量 → 统计比较 → 因果推断
```

---

## 实验设计流程

### 第一步：定义假设

**结构化假设格式：**

```
如果我们 [做某个变更]，那么 [目标指标] 将 [变化方向] [变化幅度]，
因为 [理论依据]。
```

**示例：**
> "如果我们将结账按钮从灰色改为橙色，那么结账转化率将提升 5%，
> 因为橙色更能吸引注意力（前注意属性理论）。"

### 第二步：选择指标

| 指标类型 | 含义 | 示例 |
|----------|------|------|
| **OEC (Overall Evaluation Criterion)** | 总体评估指标 | 转化率、收入、留存 |
| **Guardrail Metric** | 护栏指标（不能恶化） | 错误率、投诉率、加载时间 |
| **Diagnostic Metric** | 诊断指标（理解原因） | 点击率、停留时间、滚动深度 |

### 第三步：计算样本量

**关键参数：**

| 参数 | 含义 | 典型值 |
|------|------|--------|
| 基准率 (Baseline) | 当前指标值 | 15%（转化率） |
| MDE (最小可检测效应) | 想要检测的最小变化 | 2%（绝对）或 13%（相对） |
| 统计功效 (Power) | 检测到真实效应的概率 | 80% |
| 显著性水平 (Alpha) | 假阳性率 | 5% |

**样本量计算：**
```
每组样本量 ≈ 2 × (Z_α/2 + Z_β)² × p × (1-p) / MDE²
```

### 第四步：随机分配

**分配策略：**

| 策略 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| 简单随机 | 大多数实验 | 简单、无偏 | 小样本可能不平衡 |
| 分层随机 | 用户异质性高 | 保证各组分布一致 | 需要预分类 |
| 聚类随机 | 社交网络实验 | 避免溢出效应 | 需要更大样本 |

### 第五步：运行实验

**运行规则：**

1. **最小运行时间** — 至少覆盖一个完整业务周期（通常 1-2 周）
2. **避免 peeking** — 不要在达到统计显著性前停止实验
3. **监控护栏指标** — 如果护栏指标恶化，及时停止
4. **记录外部因素** — 节假日、营销活动、竞品动作

## 结果分析

### 统计检验

| 数据类型 | 检验方法 | 适用场景 |
|----------|----------|----------|
| 比例（转化率） | 双比例 Z 检验 | 转化率、点击率 |
| 均值（时长、金额） | 双样本 t 检验 | 平均订单金额、停留时间 |
| 计数（次数） | 泊松回归 | 使用次数、页面浏览数 |
| 时间到事件 | 生存分析 | 留存、首次购买时间 |

### 结果解读

| p 值 | 结论 | 行动 |
|------|------|------|
| < 0.05 且效应方向符合假设 | 统计显著 | 全量发布 |
| < 0.05 但效应方向相反 | 统计显著（负面） | 回滚或进一步研究 |
| ≥ 0.05 | 不显著 | 保持现状或迭代假设 |

### 效应大小 > p 值

**关键原则：** 统计显著 ≠ 实际有意义。

| 场景 | 转化率变化 | p 值 | 行动 |
|------|-----------|------|------|
| 大样本小效应 | +0.1% | < 0.001 | 可能不值得全量发布 |
| 小样本大效应 | +5% | 0.08 | 值得进一步验证 |
| 大样本大效应 | +3% | < 0.001 | 全量发布 |

## 最佳实践

### 实验设计

1. **一次只测试一个变量** — 多变量混淆因果推断
2. **预设停止规则** — 避免 peeking 导致的假阳性
3. **样本量充足** — 使用功效分析计算最小样本
4. **随机化单位正确** — 用户级 vs 会话级 vs 页面级
5. **护栏指标先行** — 先定义不能恶化的指标

### 实验运行

1. **A/A 测试验证** — 先跑 A/A 测试确认随机化正确
2. **冷启动期** — 新用户可能有新奇效应，排除前 1-2 天
3. **周末效应** — 考虑周期性波动，运行完整周期
4. **监控数据质量** — 检查随机化平衡、样本比例

### 结果解读

1. **效应大小优先** — 关注实际意义，不只是 p 值
2. **细分分析** — 检查不同用户群体的异质性效应
3. **长期效应** — 短期提升可能是 novelty effect
4. **复现实验** — 重要决策前复现关键实验

## 常见陷阱

1. **Peeking** — 在达到显著性前停止实验，假阳性率高达 40%+
2. **Multiple Comparisons** — 测试多个指标不校正，假阳性增加
3. **Novelty Effect** — 用户因新奇而改变行为，非长期效果
4. **Simpson's Paradox** — 细分趋势与总体趋势相反
5. **Sample Ratio Mismatch** — 实际分配比例与预期不符，数据污染

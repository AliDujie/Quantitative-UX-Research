# MaxDiff 优先级排序方法指南

> 基于 Chapman & Rodden《Quantitative User Experience Research》(2023)

---

## MaxDiff 概述

MaxDiff（Maximum Difference Scaling）是一种强制选择排序技术，用户从一组选项中选择"最重要"和"最不重要"的项，通过多次选择推导出完整优先级排序。

### 为什么用 MaxDiff？

| 方法 | 问题 | MaxDiff 优势 |
|------|------|-------------|
| 评分（1-5分） | 尺度偏差、天花板效应 | 强制区分，无尺度偏差 |
| 排序（全部排序） | 选项多时认知负担重 | 每次只选2个，认知负担低 |
| 配对比较 | 比较次数过多 (n×(n-1)/2) | 高效设计，少量任务覆盖全部 |

## MaxDiff 实验设计

### 基本流程

```
1. 定义待排序的选项列表（通常 8-20 项）
2. 使用平衡不完全区组设计 (BIBD) 生成任务
3. 每个任务展示 4-5 个选项
4. 用户选择"最重要"和"最不重要"
5. 通过计数分析或层级贝叶斯计算效用分数
```

### 设计参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 选项总数 | 8-20 | 太少信息不足，太多任务过多 |
| 每任务选项数 | 4-5 | 平衡认知负担和信息量 |
| 任务数 | 10-15 | 确保每对选项至少比较一次 |
| 样本量 | ≥ 100 | 个体级别分析需要更大样本 |

### 实验设计方法

**平衡不完全区组设计 (BIBD)：**
- 每个选项出现次数相同
- 每对选项共同出现次数相同
- 保证统计平衡性

**随机设计：**
- 随机生成任务组合
- 实现简单
- 可能需要更多任务

## 数据分析

### 计数分析（简单方法）

```
效用分数 = (被选为"最重要"的次数) - (被选为"最不重要"的次数)
```

**归一化：**
```
归一化分数 = 效用分数 / 任务数 × 100
范围：-100 到 +100
```

### 层级贝叶斯（高级方法）

- 考虑个体差异
- 提供个体级别效用分数
- 需要专用软件或库

### 结果解读

| 分数范围 | 含义 |
|----------|------|
| > 30 | 高优先级，强烈需求 |
| 10-30 | 中等优先级，有价值 |
| -10 到 10 | 低优先级，中性 |
| < -10 | 负面优先级，不需要 |

### 选项列表（12 项功能）

## 最佳实践

1. **选项描述清晰** — 每个选项用简洁语言描述，避免技术术语
2. **选项数量适中** — 8-12 项最佳，超过 15 项需要更多任务
3. **提供"都不重要"选项** — 允许用户表达所有选项都不重要
4. **注意力检查** — 插入注意力检查题确保数据质量
5. **移动端适配** — 确保在移动设备上良好展示

---

## 常见陷阱

1. **选项过多** — 超过 20 项时任务数激增，用户疲劳
2. **选项描述模糊** — 用户无法区分相似选项
3. **样本偏差** — 仅内部员工参与，不代表真实用户
4. **忽略个体差异** — 平均分数可能掩盖不同用户群体的差异
5. **一次性使用** — MaxDiff 应定期重复，优先级随时间变化
